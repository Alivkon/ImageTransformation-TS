# Отчёт: замена бренда на «Портрет из фото»

Дата: 2026-08-23 (UTC)

## Результат

Во всех пользовательских HTML-страницах отображаемое название `ImageTransformation` / `Image Transformation` заменено на «Портрет из фото». Замена охватывает шапки, подвалы, заголовки вкладки, метаописания, структурированные данные, форму авторизации и юридические тексты.

Графические логотипы приложения со старой надписью заменены текстовым элементом «Портрет из фото». Для него добавлены адаптивные стили, предотвращающие перенос названия на новую строку.
