# Отчёт о блоках перекрёстных ссылок

Дата: 2026-08-25

## Результат

На всех восьми публичных статических страницах проекта добавлен блок с заголовком «Если вы хотите сделать…».

В каждом блоке размещены семь коротких карточек со ссылками на все остальные публичные страницы. Текущая страница из собственного блока исключена, поэтому самоссылок нет.

## Область изменений

В работу вошли публичные страницы из `content/site/`:

- главная страница;
- деловой портрет;
- улучшение группового фото;
- реставрация старых фото;
- раскрашивание чёрно-белого фото;
- живописный портрет на юбилей;
- инструкция по использованию;
- страница о сервисе.

Служебные HTML-файлы оплаты, администрирования, юридических документов и подтверждения поисковых систем не менялись: они не входят в набор пользовательских страниц `content/site/`.

## Промежуточные шаги

1. Прочитаны корневые инструкции `AGENTS.md`.
2. Найдены HTML-файлы и проверено разделение публичных страниц, служебных документов и приложения.
3. Изучены доменные маршруты в `src/domains.ts` и `src/webServer.ts`.
4. Проверен общий стиль карточек в `static/site.css`; существующие классы `cards`, `card` и `tag` позволяют добавить блок без нового CSS.
5. Составлена матрица из восьми канонических URL и для каждой страницы исключён её собственный URL.
6. Встроенный `apply_patch` оказался недоступен из-за ошибки сетевого namespace песочницы; после неуспешной попытки эквивалентные точечные замены выполнены в разрешённом рабочем контуре.
7. На главной существующий список сценариев преобразован в требуемый блок, на остальных семи страницах блок добавлен перед финальным призывом к действию.

## Проверки

- `git diff --check` — успешно, ошибок пробелов и патча нет.
- Автоматическая проверка исходных HTML — на каждой странице один заголовок блока и ровно семь карточек.
- Проверка полной матрицы ссылок — каждый блок содержит все семь остальных URL, без пропусков, лишних ссылок и самоссылок.
- `yarn build` — успешно.
- Локальная HTTP-проверка всех восьми маршрутов — каждый ответил статусом 200 и отдал блок с семью карточками.
